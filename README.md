# Ajinkya & Mansi — Wedding Invitation

Private development repository for the December 2026 wedding website.

## Preview locally
1. Open `index.html` in GitHub.
2. Select **Raw** and save the file as `index.html` on your computer.
3. Open the saved file in Chrome. The stylesheet and JavaScript are embedded, so no other files are required.

## Included in this draft
- Royal burgundy and antique-gold visual design.
- Responsive layout and mobile navigation.
- Centre-opening invitation animation.
- Live countdown to 10 December 2026, 12:00 noon IST.
- Expandable event cards for the five confirmed functions.
- Story, venue, RSVP and gallery sections.
- User-triggered ambient audio toggle.

## Still pending before launch

## Privacy
Keep this repository private during development. Do not commit guest lists, phone numbers, RSVP responses, or other sensitive guest data to the public-facing website.
